Two kinds of code

At work I set up and run CNC machines: load the program, zero the tools, check the part against the drawing. In the evenings I write a different kind of code — HTML, CSS and JavaScript.

Both jobs reward the same habit: measure twice, cut once. A G-code program and a web page are both instructions that have to be exact, or the result comes out wrong.
